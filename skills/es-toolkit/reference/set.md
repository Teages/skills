
# Set Utilities

This page lists all set utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| countBy | Counts the occurrences of items in a Set based on a transformation function. | [countBy](reference/set/countBy.md) |
| every | Tests whether all elements in a Set satisfy the provided predicate function. | [every](reference/set/every.md) |
| filter | Filters a Set based on a predicate function. | [filter](reference/set/filter.md) |
| find | Finds the first element in a Set for which the predicate function returns true. | [find](reference/set/find.md) |
| forEach | Executes a provided function once for each element in a Set. | [forEach](reference/set/forEach.md) |
| keyBy | Maps each element of a Set based on a provided key-generating function. | [keyBy](reference/set/keyBy.md) |
| map | Creates a new Set with elements transformed by the provided function. | [map](reference/set/map.md) |
| reduce | Reduces a Set to a single value by iterating through its elements and applying a callback function. | [reduce](reference/set/reduce.md) |
| some | Tests whether at least one element in a Set satisfies the provided predicate function. | [some](reference/set/some.md) |
