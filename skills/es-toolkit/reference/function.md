
# Function Utilities

This page lists all function utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| after | Creates a new function that invokes the original function starting from the `n`-th call. | [after](reference/function/after.md) |
| ary | Creates a new function that limits the number of arguments a function can accept. | [ary](reference/function/ary.md) |
| asyncNoop | A function that asynchronously does nothing. | [asyncNoop](reference/function/asyncNoop.md) |
| before | Creates a new function that limits the number of times a function can be called. | [before](reference/function/before.md) |
| curry | Curries a function so it can be called with one argument at a time. | [curry](reference/function/curry.md) |
| curryRight | Curries a function from right to left so it can be called with one argument at a time. | [curryRight](reference/function/curryRight.md) |
| debounce | Creates a debounced function that delays the invocation of a function. | [debounce](reference/function/debounce.md) |
| flow | Creates a new function that executes multiple functions in sequence. | [flow](reference/function/flow.md) |
| flowRight | Creates a new function that executes the given functions in sequence from right to left. | [flowRight](reference/function/flowRight.md) |
| identity | Returns the input value as is. | [identity](reference/function/identity.md) |
| memoize | Caches function results so it runs faster when called again with the same arguments. | [memoize](reference/function/memoize.md) |
| negate | Creates a new function that inverts the return value of a function that returns true or false. | [negate](reference/function/negate.md) |
| noop | An empty function that does nothing. | [noop](reference/function/noop.md) |
| once | Creates a new function that limits a function to be executed only once. | [once](reference/function/once.md) |
| partial | Creates a new function with some arguments pre-applied. | [partial](reference/function/partial.md) |
| partialRight | Creates a new function with some parameters pre-applied from the right. | [partialRight](reference/function/partialRight.md) |
| rest | Creates a new function that bundles parameters from a specific index into an array and passes them to the function. | [rest](reference/function/rest.md) |
| retry | Retries a Promise-returning function until it succeeds. | [retry](reference/function/retry.md) |
| spread | Creates a new function that spreads a parameter array into individual parameters of the function. | [spread](reference/function/spread.md) |
| throttle | Limits a function to be executed at most once per specified time interval. | [throttle](reference/function/throttle.md) |
| unary | Creates a new function that limits a function to accept only the first parameter. | [unary](reference/function/unary.md) |
