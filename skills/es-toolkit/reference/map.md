
# Map Utilities

This page lists all map utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| countBy | Counts the occurrences of items in a Map based on a transformation function. | [countBy](reference/map/countBy.md) |
| every | Tests whether all entries in a Map satisfy the provided predicate function. | [every](reference/map/every.md) |
| filter | Filters a Map based on a predicate function. | [filter](reference/map/filter.md) |
| findKey | Finds the first key in a Map for which the predicate function returns true. | [findKey](reference/map/findKey.md) |
| findValue | Finds the first value in a Map for which the predicate function returns true. | [findValue](reference/map/findValue.md) |
| forEach | Executes a provided function once for each entry in a Map. | [forEach](reference/map/forEach.md) |
| hasValue | Checks if a Map contains a specific value. | [hasValue](reference/map/hasValue.md) |
| keyBy | Maps each entry of a Map based on a provided key-generating function. | [keyBy](reference/map/keyBy.md) |
| mapKeys | Creates a new Map with the same values but with keys transformed by the provided function. | [mapKeys](reference/map/mapKeys.md) |
| mapValues | Creates a new Map with the same keys but with values transformed by the provided function. | [mapValues](reference/map/mapValues.md) |
| reduce | Reduces a Map to a single value by iterating through its entries and applying a callback function. | [reduce](reference/map/reduce.md) |
| some | Tests whether at least one entry in a Map satisfies the provided predicate function. | [some](reference/map/some.md) |
