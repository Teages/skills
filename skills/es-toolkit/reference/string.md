
# String Utilities

This page lists all string utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| camelCase | Converts a string to camel case. | [camelCase](reference/string/camelCase.md) |
| capitalize | Converts the first character of a string to uppercase and the remaining characters to lowercase. | [capitalize](reference/string/capitalize.md) |
| constantCase | Converts a string to constant case. | [constantCase](reference/string/constantCase.md) |
| deburr | Converts special characters and diacritics to ASCII characters. | [deburr](reference/string/deburr.md) |
| escape | Converts characters with special meaning in HTML to safe entities. | [escape](reference/string/escape.md) |
| escapeRegExp | Escapes characters with special meaning in regular expressions to literal characters. | [escapeRegExp](reference/string/escapeRegExp.md) |
| kebabCase | Converts a string to kebab case. | [kebabCase](reference/string/kebabCase.md) |
| lowerCase | Converts a string to lower case format. | [lowerCase](reference/string/lowerCase.md) |
| lowerFirst | Converts the first character of a string to lowercase. | [lowerFirst](reference/string/lowerFirst.md) |
| pad | Pads a string on both sides to reach a specified length. | [pad](reference/string/pad.md) |
| pascalCase | Converts a string to pascal case. | [pascalCase](reference/string/pascalCase.md) |
| reverseString | Reverses a string. | [reverseString](reference/string/reverseString.md) |
| snakeCase | Converts a string to snake case. | [snakeCase](reference/string/snakeCase.md) |
| startCase | Converts the first letter of each word in a string to uppercase. | [startCase](reference/string/startCase.md) |
| trim | Removes whitespace or specified characters from the beginning and end of a string. | [trim](reference/string/trim.md) |
| trimEnd | Removes whitespace or specified characters from the end of a string. | [trimEnd](reference/string/trimEnd.md) |
| trimStart | Removes whitespace or specified characters from the start of a string. | [trimStart](reference/string/trimStart.md) |
| unescape | Converts HTML entity characters to their original characters. | [unescape](reference/string/unescape.md) |
| upperCase | Converts a string to a format where all letters are uppercase and words are separated by spaces. | [upperCase](reference/string/upperCase.md) |
| upperFirst | Converts the first character of a string to uppercase. | [upperFirst](reference/string/upperFirst.md) |
| words | Splits a string into an array of words. | [words](reference/string/words.md) |
