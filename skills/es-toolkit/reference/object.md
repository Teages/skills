
# Object Utilities

This page lists all object utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| clone | Creates a shallow copy of the given value. | [clone](reference/object/clone.md) |
| cloneDeep | Creates a deep copy of the given value. | [cloneDeep](reference/object/cloneDeep.md) |
| cloneDeepWith | Deeply clones the given value with a custom cloning function. | [cloneDeepWith](reference/object/cloneDeepWith.md) |
| findKey | Finds the key of the first element that satisfies the given condition. | [findKey](reference/object/findKey.md) |
| flattenObject | Converts a nested object into a flat object. | [flattenObject](reference/object/flattenObject.md) |
| invert | Creates a new object with keys and values swapped. | [invert](reference/object/invert.md) |
| mapKeys | Returns a new object with keys transformed through a function. | [mapKeys](reference/object/mapKeys.md) |
| mapValues | Returns a new object with values transformed through a function. | [mapValues](reference/object/mapValues.md) |
| merge | Deeply merges the source object into the target object, modifying the target object. | [merge](reference/object/merge.md) |
| mergeWith | Deeply merges the source object into the target object using a custom merge function, modifying the target object. | [mergeWith](reference/object/mergeWith.md) |
| omit | Returns a new object excluding the specified keys. | [omit](reference/object/omit.md) |
| omitBy | Returns a new object containing only the properties that do not satisfy the condition function. | [omitBy](reference/object/omitBy.md) |
| pick | Returns a new object containing only the properties corresponding to the specified keys. | [pick](reference/object/pick.md) |
| pickBy | Returns a new object containing only the properties that satisfy the condition function. | [pickBy](reference/object/pickBy.md) |
| toCamelCaseKeys | Returns a new object with all keys in objects and arrays converted to camelCase. | [toCamelCaseKeys](reference/object/toCamelCaseKeys.md) |
| toMerged | Returns a new object with the source object deeply merged into a copy of the target object. | [toMerged](reference/object/toMerged.md) |
| toSnakeCaseKeys | Returns a new object with all keys in objects and arrays converted to snake_case. | [toSnakeCaseKeys](reference/object/toSnakeCaseKeys.md) |
