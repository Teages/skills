
# Util Utilities

This page lists all util utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| assert | Asserts that a given condition is true. If the condition is false, it throws an error. | [assert](reference/util/assert.md) |
| attempt | Executes a function and returns the result or error as a tuple. | [attempt](reference/util/attempt.md) |
| attemptAsync | Executes an async function and returns the result or error as a tuple. | [attemptAsync](reference/util/attemptAsync.md) |
| invariant | Asserts that a given condition is true. If the condition is false, it throws an error. | [invariant](reference/util/invariant.md) |
