
# Promise Utilities

This page lists all promise utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| Mutex | Ensures that multiple asynchronous tasks do not execute simultaneously. | [Mutex](reference/promise/Mutex.md) |
| Semaphore | Limits the number of asynchronous tasks that can execute simultaneously. | [Semaphore](reference/promise/Semaphore.md) |
| delay | Delays code execution for a specified amount of time. | [delay](reference/promise/delay.md) |
| timeout | Returns a `Promise` that throws a `TimeoutError` after the specified time. | [timeout](reference/promise/timeout.md) |
| withTimeout | Sets a time limit on an asynchronous function, throwing a `TimeoutError` if it doesn't complete within the specified time. | [withTimeout](reference/promise/withTimeout.md) |
