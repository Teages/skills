
# Math Utilities

This page lists all math utilities available in es-toolkit.
| Name | Description | Link |
| --- | --- | --- |
| clamp | Clamps a number within a specified range. | [clamp](reference/math/clamp.md) |
| inRange | Checks if a value is within a specified range. | [inRange](reference/math/inRange.md) |
| mean | Calculates the average of an array of numbers. | [mean](reference/math/mean.md) |
| meanBy | Calculates the average of an array by applying the `getValue` function to each element. | [meanBy](reference/math/meanBy.md) |
| median | Calculates the median of an array of numbers. | [median](reference/math/median.md) |
| medianBy | Calculates the median of an array by applying the `getValue` function to each element. | [medianBy](reference/math/medianBy.md) |
| random | Generates a random number within a specified range. The number can include decimals. | [random](reference/math/random.md) |
| randomInt | Generates a random integer within a specified range. | [randomInt](reference/math/randomInt.md) |
| range | Creates an array of numbers within a specified range and step. | [range](reference/math/range.md) |
| rangeRight | Creates an array of numbers in reverse order within a specified range and step. | [rangeRight](reference/math/rangeRight.md) |
| round | Rounds a number to a specified number of decimal places. | [round](reference/math/round.md) |
| sum | Returns the sum of all elements in an array of numbers. | [sum](reference/math/sum.md) |
| sumBy | Calculates the sum of array elements using a transformation function. | [sumBy](reference/math/sumBy.md) |
