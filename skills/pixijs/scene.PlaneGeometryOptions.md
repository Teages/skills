# Interface: PlaneGeometryOptions

**`Advanced`**

Constructor options used for `PlaneGeometry` instances.
```js
const planeGeometry = new PlaneGeometry({
   width: 100,
   height: 100,
   verticesX: 10,
   verticesY: 10,
});
```
