# Interface: TransformableObject

**`Advanced`**

The data structure that contains the position, scale, pivot, skew and rotation of an object.
This is used by the [Matrix](maths.Matrix.md) class to decompose the matrix into its components.

## Properties

### pivot

> **pivot**: [`PointData`](maths.PointData.md)

The pivot of the object

***

### position

> **position**: [`PointData`](maths.PointData.md)

The position of the object

***

### rotation

> **rotation**: `number`

The rotation of the object

***

### scale

> **scale**: [`PointData`](maths.PointData.md)

The scale of the object

***

### skew

> **skew**: [`PointData`](maths.PointData.md)

The skew of the object
