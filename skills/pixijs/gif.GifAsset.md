# Variable: GifAsset

> `const` **GifAsset**: [`AssetExtension`](assets.AssetExtension.md)\<[`GifSource`](gif.GifSource.md), [`GifBufferOptions`](gif.GifBufferOptions.md)\>

**`Advanced`**

Handle the loading of GIF images. Registering this loader plugin will
load all `.gif` images as an ArrayBuffer and transform into an
GifSource object.
