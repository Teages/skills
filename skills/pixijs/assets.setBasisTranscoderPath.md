# Function: setBasisTranscoderPath()

> **setBasisTranscoderPath**(`config`): `void`

**`Advanced`**

Sets the Basis transcoder paths.
This allows you to override the default paths for the Basis transcoder files.

## Parameters

### config

[`Partial`](https://www.typescriptlang.org/docs/handbook/utility-types.html#partialtype)\<*typeof* [`basisTranscoderUrls`](assets.basisTranscoderUrls.md)\>

The configuration object containing the new paths.

## Returns

`void`
