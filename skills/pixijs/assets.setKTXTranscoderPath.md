# Function: setKTXTranscoderPath()

> **setKTXTranscoderPath**(`config`): `void`

**`Advanced`**

Sets the paths for the KTX transcoder library.

## Parameters

### config

[`Partial`](https://www.typescriptlang.org/docs/handbook/utility-types.html#partialtype)\<*typeof* [`ktxTranscoderUrls`](assets.ktxTranscoderUrls.md)\>

Partial configuration object to set custom paths for the KTX transcoder.
This allows you to override the default URLs for the KTX transcoder library.

## Returns

`void`
